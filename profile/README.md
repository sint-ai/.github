# SINT Labs

SINT builds autonomous agents, MCP tooling, and AI infrastructure aimed at real-world execution instead of demos.

[Website](https://www.sint.gg) | [Discord](https://discord.com/invite/nWwuT6TQ) | [X](https://x.com/sinthive) | [Telegram](https://t.me/sint_news)

## Start here

- [`sintos`](https://github.com/sint-ai/sintos) - core operating system and infrastructure for SINT AI agents
- [`sint-protocol`](https://github.com/sint-ai/sint-protocol) - open protocol for governance, security, and economic enforcement in physical AI systems
- [`twitter_mcp_server`](https://github.com/sint-ai/twitter_mcp_server) - MCP server for Twitter/X integrations
- [`image_mcp_server`](https://github.com/sint-ai/image_mcp_server) - MCP server for AI-powered image generation and editing
- [`sint-mcp-marketplace`](https://github.com/sint-ai/sint-mcp-marketplace) - stateless Hono MCP server deployable to Cloudflare Workers
- [`docs`](https://github.com/sint-ai/docs) - SINT documentation and reference material

## What to expect

- Open tooling around MCP, agent infrastructure, and execution workflows
- Repositories that graduate from internal R&D into public operator tools
- A mix of platform primitives, protocol work, and focused agent integrations
