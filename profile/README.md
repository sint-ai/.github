# SINT Labs

SINT Labs builds open-source security infrastructure for AI agents that operate
tools, data, robots, and industrial systems. Our public work focuses on runtime
governance: capability tokens, policy gateways, MCP security, robotics safety,
industrial automation controls, and tamper-evident execution evidence.

[Website](https://www.sint.gg) | [Discord](https://discord.com/invite/nWwuT6TQ) | [X](https://x.com/sinthive) | [Telegram](https://t.me/sint_news)

## What We Build

- **AI agent security:** pre-action authorization, typed deny/escalate outcomes,
  revocation, and audit evidence for autonomous workflows.
- **MCP governance:** security-first MCP proxying, tool-call interception, and
  evidence-backed policy decisions before tool execution.
- **Physical AI safety:** runtime controls for robotics, drones, smart homes,
  industrial automation, and other systems where actions affect the real world.
- **Open standards evidence:** conformance fixtures, public specs, compliance
  mappings, and submission packets for OWASP, MITRE ATLAS, AAIF, NIST, and EU AI
  Act-aligned governance.
